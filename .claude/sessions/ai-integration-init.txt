  app.post('/api/generate/context', async (req, res) => {
    const response = await fetch(GLM_ENDPOINT, {
      headers: { Authorization: `Bearer ${process.env.GLM_API_KEY}` }
    });
    // API key never leaves server
  });

  // React frontend (no API key):
  const response = await fetch('http://localhost:8000/api/generate/context', {
    body: JSON.stringify({ text: problemText })
  });

  Your API key stays server-side with both Python and Express!

  📊 The Options

  Option 1: Next.js (Full-stack React)
  - Best for new projects
  - Built-in API routes
  - Requires migration

  Option 2: Express (⭐ Recommended)
  - Keep your Vite app
  - 150 lines of code
  - 2-minute setup

  Option 3: Serverless
  - Netlify/Vercel Functions
  - No server management
  - Great for scaling
